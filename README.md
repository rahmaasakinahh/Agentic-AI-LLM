\## Project Overview



An internship research project investigating the multilingual tool-calling capabilities and linguistic robustness of Large Language Models (LLMs) in the context of Agentic AI.



The research focuses on evaluating model performance across English and Indonesian inputs, validating ground-truth annotations, analyzing function and argument prediction errors, and investigating model robustness under controlled linguistic variations.



\## Research Objectives



\- Investigate multilingual LLM tool-calling capabilities.

\- Inspect, preprocess, and validate benchmark datasets.

\- Evaluate function and argument prediction performance.

\- Explore AST-based evaluation using BFCL.

\- Analyze the impact of controlled Indonesian linguistic variations.

\- Conduct paired statistical comparisons of model performance.



\## Research Workflow



1\. Dataset inspection

2\. Exploratory data analysis

3\. Data preprocessing and deduplication

4\. Ground-truth validation and manual review

5\. Model selection and compatibility testing

6\. Baseline tool-calling evaluation

7\. BFCL AST-based evaluation

8\. Function and argument error analysis

9\. Controlled linguistic variation development

10\. Local language robustness evaluation

11\. Post-audit and paired statistical analysis



\## Technologies and Methodologies



\- Python

\- Large Language Models

\- Agentic AI and Function Calling

\- MASSIVE-based multilingual benchmark data

\- Berkeley Function Calling Leaderboard (BFCL)

\- Abstract Syntax Tree (AST) evaluation
